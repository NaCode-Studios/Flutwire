# Changelog

## 0.2.0

Needs `dio` 5.2 or later, the first release that has `DioException`: 0.1.0 allowed 5.0 and 5.1 and did not compile against them. When the interceptor stands down for the `dart:io` capture it now tells Flutwire, so that Flutwire can say above the list when the capture never recorded the call. Adds an example, and needs `flutwire` 0.2.0. The [repository changelog](https://github.com/NaCode-Studios/Flutwire/blob/main/CHANGELOG.md#020---2026-10-24) lists what the other packages gained.
